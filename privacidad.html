Política de privacidad

Última actualización: 12 de septiembre de 2026.

Datos tratados

MECPRO procesa los datos necesarios para crear y preparar vídeos cortos. Cuando el usuario conecta una plataforma externa, se pueden procesar identificadores de cuenta, tokens de autorización y datos técnicos necesarios para ejecutar la acción solicitada.

Uso y conservación

Los datos se utilizan para autenticar la cuenta conectada, preparar el contenido solicitado, enviarlo a la plataforma elegida y consultar su estado. Se conservan solo durante el tiempo necesario para prestar la función y resolver incidencias.

Seguridad

Las credenciales y tokens se almacenan como secretos y no forman parte de la web pública. No vendemos datos personales ni los utilizamos para publicidad propia.

Eliminación

El usuario puede revocar permisos desde la plataforma conectada y solicitar la eliminación de los datos escribiendo a basky.canal01@gmail.com.
